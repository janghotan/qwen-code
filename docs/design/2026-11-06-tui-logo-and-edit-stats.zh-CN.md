# 终端界面标志与编辑统计

[English](2026-11-06-tui-logo-and-edit-stats.md) | [简体中文](2026-11-06-tui-logo-and-edit-stats.zh-CN.md)

## 问题

终端横幅仍显示 Qwen Code 字样和标题。成功编辑文件时，也没有简洁地显示模型修改的行数。

## 目标与范围

- 在 Ink 和 OpenTUI 横幅中显示用户提供的蓝色 Qwen 图标，并将产品标为 `Engineering Edition`。
- 保留自定义横幅图案和标题。
- 在成功的文件编辑操作旁显示模型新增和删除的行数，分别使用绿色和红色。
- 仅修改终端渲染；不改动认证、提供方或模型设置。

## 设计

使用紧凑的 Unicode 块字符绘制该图标，颜色采用从原图采样的 `#072efe`。自定义横幅图案继续使用现有主题渐变路径。将 `FileDiff.diffStat` 中的两个模型行数通过 OpenTUI 结构化结果事件传递，并在操作行显示。Ink 直接从现有 `FileDiff` 结果读取相同字段。若统计缺失或操作未成功，则不显示计数。

此方案复用现有横幅和文件差异数据路径。终端图像协议在支持的终端中表现不一致；展示全部差异统计也超出了本次要求。

## 验证

运行 Ink 和 OpenTUI 横幅、事件适配器、转录视图及工具消息的定向测试；运行 CLI 类型检查、lint、构建和打包。使用 `node dist/cli.js --version` 验证构建后的 CLI。不发起实时模型请求。

## 验收标准

两个终端后端都显示蓝色图标和 `Engineering Edition`；自定义品牌仍可用；成功的文件编辑显示绿色和红色的 `(+N)(-N)` 计数；本地 CLI 测试和构建通过。
